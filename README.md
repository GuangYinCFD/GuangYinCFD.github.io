# Guang Yin 尹光

Academic homepage of Dr. Guang Yin, University of Stavanger.

Website: https://guangyincfd.github.io

## Edit the website

- `_pages/home.md`: biography and homepage
- `_pages/resume.md`: education and academic appointments
- `_pages/publications.md`: publications
- `_pages/research.md`: research gallery
- `_pages/projects.md`: SMARTFLUIDS project
- `_pages/students.md`: supervision
- `_pages/events.md`: events
- `_pages/contact.md`: contact details
- `_config.yml`: profile, social links, website settings
- `_data/navigation.yml`: navigation menu

Changes committed to `main` are automatically built and deployed through GitHub Actions. Files committed directly to this repository take precedence over the bundled template.

The `academic-site.zip.001`–`.012` files contain the Academic Pages theme and original migrated assets. The read-only build verifies their checksum and extracts them in its temporary workspace. It never commits or pushes repository changes. Keep these twelve files together.
